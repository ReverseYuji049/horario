> **Resumo do Google Docs:**\
> O que é Machine Learning?
> Machine Learning é uma área de estudo da inteligência artificial concentrada no desenvolvimento e estudo de algoritmos estatísticos que conseguem aprender através de dados e generalizar dados novos e, assim, realizar tarefas sem instruções explícitas. 
>
> **Aprendizado Supervisionado**
> - Features | Variáveis de Input: um dataset com um determinado número de dados independentes.
> - Target | Labels | Variáveis de Output: um dataset com dados dependentes que será utilizado para a previsão. 
> - Training Dataset (True Values | Labeled Data): utilizado para treinar nosso algoritmo que irá realizar a previsão as variáveis de output.
>   Exemplo: Preço de Casas
>
> **Aprendizado Não Supervisionado**
> São fornecidos dados não rotulados, sem conhecimento prévio, para o algoritmo realizar agrupamentos por similaridade.
> Exemplo: Emails
> O algoritmo deve organizar todos os seus e-mails em categorias não especificadas. Ele irá definir por si próprio como irá criar essas categorias, chamadas de clusters. 
>
> **Subcategorias de Aprendizado Supervisionado**
> **Regressão**
> A regressão realiza a previsão de dados contínuos e numéricos.
> **Classificação**
> A classificação realiza a previsão de dados categóricos (labels/classes).
> Exemplo: Labels/Rótulos Spam ou Não Spam
>
> **Algoritmos de Machine Learning**
> **Linear Regression (Regressão Linear)**
> No geral, algoritmos de aprendizado supervisionado buscam determinar a relação entre duas variáveis (input e output), encontrando a função que mapeia uma à outra.
> Aqui, buscamos encaixar uma equação linear aos dados, minimizando a soma dos quadrados das distâncias entre os pontos dos dados e a linha de regressão no gráfico.
> Isso permite minimizar a distância média entre os valores reais e o nosso modelo de previsão, nesse caso, a Regression Line. Também diminui erros de previsão para novos pontos de dados.
>
> Exemplo 1: Salário x Experiência\
> [Imagem Não Exportada]\
> Exemplo 2: Altura x Tamanho do Sapato\
> [Imagem Não Exportada]\
>No exemplo, a cada unidade acrescentada ao tamanho do sapato, duas unidades são acrescentadas à altura. 
>
> **Logistic Regression**
> A regressão logística é uma variante da regressão linear. Em vez de encaixar uma linha para duas variáveis numéricas com uma relação presumida, tentamos prever uma variável de output categórica utilizando variáveis de input categóricas ou numéricas.\
> Exemplo: Altura e Peso x Gênero\
> [Imagem Não Exportada]
>No exemplo, queremos descobrir o gênero de uma pessoa com base em sua altura e peso.
> A equação agora nos diz a probabilidade de um ponto de dado cair em uma certa categoria, dado o valor da variável de input.
>
>**K Nearest Neighbors (KNN)**
> A ideia central do K Nearest Neighbors é que para cada novo dado, nós iremos prever um alvo (target) para ser a média de K.
> Pode ser utilizado para ambas as subcategorias. 
> Também é conhecido como algoritmo não parametrizado. Isso significa que não tentamos encaixar nenhuma equação e, assim, encontrar qualquer parâmetro do modelo, então não é necessário nenhum True Model Fitting.
>
> Exemplo em Classificação: Altura e Peso x Gênero\
> [Imagem Não Exportada]\
> Aqui, o gênero de uma pessoa é o mesmo que o das 5 pessoas mais próximas em peso e altura.
> Exemplo em Regressão: Altura e Peso x Gênero\
> [Imagem Não Exportada]\
> O peso de uma pessoa é a média das três pessoas mais próximas em altura e em circunferência do tórax.
>
> K é o hiperparâmetro do algoritmo e escolhê-lo corretamente garante um bom treinamento do seu modelo.
> - Under-Fitting (K muito grande): o pior de todos os casos.
> - Appropriate-Fitting: o caso ideal, dependendo do problema trabalhado.
> - Overfitting (K pequeno): previsão boa, mas não generaliza bem para dados não vistos.
> Um dos métodos para achar o melhor hiperparâmetro é a Cross Validation (validação cruzada).
>
> **Support Vector Machine (SVM)**
> Foi originalmente projetada para tarefas de classificação, mas também pode ser utilizada para regressão.
> A ideia do SVM é desenhar uma linha de decisão entre dados que separa os dados de treinamento, assim como um novo dado não visto que será classificado em determinada classe se atender ao critério da linha de decisão.
>
> No exemplo a seguir, ao classificar elefantes e gatos, a linha de decisão será reta. O algoritmo tentará separar as classes com a maior margem possível que maximize o espaço entre as diferentes classes. 
> Isso faz com que o algoritmo faça uma boa generalização e seja menos sensível a ruídos e outliers nos dados de treinamento.
>
> Também há os support vectors (sublinhados de amarelo) que estão na borda da margem. Eles são o suficiente para classificar novos dados
> Uma de suas principais vantagens é que a SVM é poderosa com grandes dimensões, ou seja, quando o número de features/variáveis de input é maior em comparação ao tamanho dos dados.
